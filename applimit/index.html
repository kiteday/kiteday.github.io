앱리밋 개인정보처리방침

시행일: 2026년 9월 22일

앱리밋(이하 “앱”)은 사용자가 자신의 앱 사용 시간을 관리하도록 돕는 앱입니다. 본 방침은 앱이 정보를 처리하는 방법을 설명합니다.

요약: 앱은 회원가입, 자체 서버, 광고 및 분석 도구를 사용하지 않습니다. 설정 정보는 기기에만 저장되며 외부로 전송되지 않습니다.

1. 수집하지 않는 정보

앱은 이름, 이메일, 전화번호, 위치정보 등 사용자를 식별하는 개인정보를 수집하거나 외부 서버로 전송하지 않습니다.

2. Screen Time 데이터

사용 시간은 Apple의 Screen Time 기능이 기기 안에서 처리합니다. 앱은 개별 앱의 실제 사용 시간이나 사용자가 선택한 앱의 이름 및 식별자를 읽을 수 없습니다. Apple 시스템 선택 화면의 선택 결과는 불투명한 토큰으로만 전달됩니다.

3. 기기에 저장되는 정보

  • Apple 시스템 선택 화면에서 전달된 불투명한 앱 토큰
  • 앱별 하루 한도와 알림·잠금 설정
  • 당일 알림 여부와 추가 사용 횟수

이 정보는 앱과 Screen Time 익스텐션이 함께 동작할 수 있도록 기기의 App Group 저장소에만 보관되며 기기 밖으로 전송되지 않습니다.

4. 알림

한도 도달 알림은 기기에서 생성되는 로컬 알림입니다. 외부 서버를 사용하지 않으며 알림 권한은 iOS 설정에서 언제든 변경할 수 있습니다.

5. 제3자 서비스

앱은 광고 SDK, 분석 SDK 또는 제3자 추적 도구를 포함하지 않습니다.

6. 방침 변경

앱 기능이나 관련 법령이 변경되면 본 방침을 수정할 수 있으며, 변경 내용과 시행일은 이 페이지에 게시합니다.
